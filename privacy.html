Privacy Policy

Last updated: 30 September 2026

Hermes ("the application") is a personal AI assistant used by a single individual, its owner. The application is not a public product and has no users other than its owner.

What Google data the application accesses

The application uses the Google Calendar API to access the owner's own Google Calendar. It reads existing events and creates, updates or deletes events only when the owner explicitly asks it to. It uses the following Google OAuth scope: https://www.googleapis.com/auth/calendar.

The application does not access Gmail, Google Drive, Google Contacts, or any other Google service.

How the data is used

Calendar data is used exclusively to display, create, update or delete events in the owner's own calendar, following the owner's instructions. The data is never used for advertising, profiling, analytics, or any purpose other than carrying out those instructions.

How the data is stored and protected

OAuth credentials, access tokens and refresh tokens are stored only on the owner's own computer, in files readable exclusively by the owner's user account. They are not transmitted to, or stored on, any third-party server operated by the application.

Data sharing

No Google user data is sold, rented, transferred or shared with any third party. The application's use of Google user data adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Calendar data is not retained by the application beyond what is needed to carry out the instruction in progress. The owner can revoke the application's access at any time from the Google Account permissions page (myaccount.google.com/permissions). Revoking access invalidates the stored tokens immediately.
